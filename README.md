# じゃんけんゲーム

コンピュータとじゃんけんで対戦できる、Python 製のシンプルなゲームです。

## 必要なもの
- Python 3

## 動かし方
```
git clone https://github.com/takumi0901-hub/janken-game.git
cd janken-game
python janken.py
```

## 遊び方
1. 表示される案内に従って、数字を入力します。
   - `0`: グー
   - `1`: チョキ
   - `2`: パー
   - `9`: 終了
2. コンピュータがランダムに手を出し、勝ち・負け・あいこが表示されます。
3. `9` を入力するまで、何度でも遊べます。# jyanken
